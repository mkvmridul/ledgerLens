# Prior work: what existed before 09:00 on 18 September 2026

The finalist briefing asks teams to say what existed before build day and what was built during the event. This file is that declaration. It was committed before build day so the timestamp supports it; the git history shows the same.

Everything listed below was written between 17 September and the morning of 18 September, and was verified against a **local** Elasticsearch 9.5.4 + Kibana 9.5.4 running in Docker on a laptop. The build was done with AI pair-programming assistance (Claude Code), with every step run and checked by the team.
